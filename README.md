# local-tutorial-tracker

Welcome to your completely upgraded, modern Local Tutorial Tracker!

## How To Use
1. Extract all files into a single folder on your PC.
2. Ensure `index.html`, `styles.css`, and `script.js` are in the same folder.
3. Open `index.html` in Chrome or Microsoft Edge (or use a local Live Server).
4. Click **Open course folder** and select the root directory containing your course videos and files.

## Features & Upgrades
- **Modern Glassmorphism UI:** Beautiful dark mode with blurred semi-transparent panels.
- **Modularized Codebase:** The HTML, CSS, and JS have been separated into distinct files for easier maintenance.
- **Auto-Preview:** If a lesson contains only resources (like a standalone PDF), it will instantly load into the main viewer!
- **Improved Video Player:** Added Picture-in-Picture mode, Playback Speed controls, and Keyboard Shortcuts (`Space`/`K` for Play/Pause, `F` for Fullscreen).
- **Stable Sidebar:** Tracking progress no longer causes your folders to forcefully collapse!
- **Progress & Notes Backup (NEW):** Easily export your entire watch history, notes, and timestamps to a backup file (`⬇ Export`), and restore them anytime (`⬆ Import`).
- **Custom Bookmarks (NEW):** Add specific timestamps and notes directly to a video timeline.
- **Global Search (NEW):** Search for specific keywords across all notes and bookmarks you've written.

## What Opens Inside The App
- **PDF:** Displayed in the main viewer seamlessly.
- **HTML/HTM:** Displayed directly in the app.
- **Code & Text:** (TXT, MD, CSV, JSON, PY, JS, CSS) Displayed inside a styled code block.
- **.BIN files:** Listed, but requires external opening.

## PowerPoint and Office Files
Web browsers cannot directly render private local PPT/PPTX, Word, or Excel files. Use the **Open externally** button to launch the installed Microsoft Office application. Convert PowerPoint to PDF if an in-app slide preview is required.

---
*Note: All files stay on your computer. Progress and notes are stored locally in your browser.*
